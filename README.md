# Mi Cocina — PWA

Esta versión está preparada para instalarse como una aplicación en iPhone/iPad mediante Safari y como PWA en navegadores compatibles.

## Para publicarla
Necesitas alojar esta carpeta en un servicio HTTPS (por ejemplo GitHub Pages, Netlify o Vercel).

Después, en iPhone:
1. Abre la URL en Safari.
2. Pulsa Compartir.
3. Selecciona "Añadir a pantalla de inicio".
4. Pulsa "Añadir".

El service worker permite que la aplicación siga funcionando sin conexión después de haber sido cargada.

Los datos del inventario siguen guardándose localmente en el navegador/dispositivo en esta primera versión.
